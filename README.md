# MediaFactory — Legal Pages

Static privacy policy, terms of service, and data-deletion pages for MediaFactory and its
Meta developer application **“Shahjahan”** (App ID `925154770209491`).

## Files

| File | Purpose | Use for |
|------|---------|---------|
| `index.html` | Privacy Policy | Meta App Settings → Privacy Policy URL |
| `terms.html` | Terms of Service | Meta App Settings → Terms of Service URL |
| `data-deletion.html` | Data Deletion Instructions | Meta App Settings → User Data Deletion URL |

## Publishing to GitHub Pages

1. Push this repo to GitHub (branch `main`).
2. Repo → Settings → Pages → Source: **Deploy from a branch** → Branch `main`, folder `/ (root)`.
3. Wait ~1 minute. The pages go live at:

```
https://bayazidhabibsiddikee.github.io/privacy-policy/
https://bayazidhabibsiddikee.github.io/privacy-policy/terms.html
https://bayazidhabibsiddikee.github.io/privacy-policy/data-deletion.html
```

## URLs to paste into the Meta App Dashboard

Go to <https://developers.facebook.com/apps/925154770209491/settings/basic/>:

- **Privacy Policy URL** → `https://bayazidhabibsiddikee.github.io/privacy-policy/`
- **Terms of Service URL** → `https://bayazidhabibsiddikee.github.io/privacy-policy/terms.html`
- **User Data Deletion** → choose *Data Deletion Instructions URL* →
  `https://bayazidhabibsiddikee.github.io/privacy-policy/data-deletion.html`

These URLs must be publicly reachable over HTTPS. GitHub Pages provides valid HTTPS
automatically once the site is published.
